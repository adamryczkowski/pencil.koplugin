# pencil.koplugin documentation

End-user and codebase documentation for the pencil.koplugin lives here.

Contents are generated by the orchestrator-driven planning workflow as a
side-effect of feature implementation (the orchestrator's "describe to
test" pass), or written by hand. None has been generated yet for the
current scope; this folder is staged for future content.

For now:
- Feature roadmap and plan history: see `pencil.koplugin/main.lua` source
  comments and the upstream README.
- On-device manual regression testing: `manual-test/PLAYBOOK.md`.
